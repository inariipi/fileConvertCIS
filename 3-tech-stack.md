# Tech Stack & Hosting Strategy

## Defined Tech Stack

*   `Language / Framework / Tool 1`: ffmpeg -  Existing tool that converts file types like png to jpeg.

*   `Language / Framework / Tool 2`: SwiftUI - Used to create front-end UI for users.
*   `Language / Framework / Tool 3`: Python -  Very simple application, so a language like Python can help create it with ease.

## Hosting & Deployment Strategy

The application will be **locally run software** and downloadable from the GitHub page for fileConvert.
