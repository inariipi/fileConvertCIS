# Risk Mitigation & Technical Constraints

## Core Technical Risks

*   **Highest Risk Feature:** File Sharing

*   **The Hazard:** Possible privacy concern as connections would be p2p, also lack of networking experience on the developer team.

## The Pivot Strategy

If our primary implementation for this feature fails or takes too long, our backup plan is to:

Drop the feature until someone more competent or the development team gains more networking knowledge.
fileConvert isn't based around the file sharing feature, so delaying it is worth the otherwise safety risk.
