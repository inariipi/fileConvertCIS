**fileConvert feature overview**

*Typical file conversion*
As implied by the name, fileConvert converts any file type to any other desired one.

*GUI*
fileConvert has an easy-to-use GUI, requiring no terminal use.

*Convert on right-click*
fileConvert can also convert any file by right-clicking a given file and choosing the "convert to" button

*Atypical file conversion*
fileConvert can not only do simple conversions like jpeg to png, but more complex ones like png to pdf and odd ones such as png to mp3.

*File sharing*
It can also share simple small files between clients, allowing easy file transfer.
